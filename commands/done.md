description: Mark this session as done - prefix the session and cmux workspace title with "DONE:" and colour the workspace green
---

Run `~/.config/opencode/scripts/mark.sh DONE Green` with the shell tool. It replaces any existing prefix such as `STORY:` or `BLOCK:` with `DONE:`, renames the cmux workspace and this session, and sets the workspace colour to green. Report the resulting title, or the error if it fails. Do nothing else.
